# IVT Guard landing

Коммерческий лендинг защитного OpenRTB-аудита IVT Guard.

## Локальный запуск

```bash
npm ci
npm run dev
```

Production-проверка:

```bash
npm test
```

Сайт не собирает персональные данные и не подключается к рекламным кабинетам. Форма первого контакта ведёт в профиль исполнителя на FL.ru. Все показатели в демонстрационном отчёте синтетические и совпадают с воспроизводимым набором из корня проекта.
